# STM32F4 裸机实时操作系统(教学级抢占式内核)

一个从零手写的 **Cortex-M4 (STM32F407,168MHz)** 抢占式多任务内核与演示工程。
不依赖任何 RTOS 源码,中断(向量表、SVC/PendSV/SysTick 上下文切换)与调度逻辑全部自己实现。

## 特性

- **抢占式优先级调度**:4 级优先级(0 最高),同一优先级按 SysTick 时间片轮转
- **完整上下文切换**:SVC 启动首任务,PendSV 完成日常切换,硬件压栈 + 手动保存 r4-r11
- **阻塞延时**:`rtos_delay` 挂入睡眠队列,SysTick 统一唤醒,不忙等
- **信号量**:阻塞/唤醒/令牌计数,支持任务创建与内存池等内部使用
- **互斥锁(mutex)**:阻塞等待 + **优先级继承**(防优先级反转)+ 锁转交(零延迟让位)
- **可嵌套临界区**:保存/恢复 PRIMASK,内层不会误开外层临界区
- **静态内存池**:TCB、任务栈、多规格堆(32/64/128/256B)全部池化管理,无动态内存碎片
- **现象可观测**:功能测试全部映射到 GPIO,配合逻辑分析仪即可验证调度/同步行为

## 目录结构

```
├── src/
│   ├── start.s          # 向量表 + 启动代码(调用 systeminit 配 168MHz)
│   ├── rtos.c           # 内核:任务创建/调度器/延时/可嵌套临界区
│   ├── port.c           # 移植层:SysTick / PendSV / SVC 中断处理
│   ├── queue.c          # 通用双向链表队列(就绪/睡眠/等待队列的基础)
│   ├── memory.c         # TCB/栈/堆内存池
│   ├── semaphore.c      # 信号量
│   ├── mutex.c          # 互斥锁(优先级继承)
│   ├── gpio.c           # GPIO 简易驱动
│   ├── clk.c / flash.c  # 时钟初始化 / Flash 擦写
│   └── main.c           # 功能演示(两阶段自动循环)
├── include/             # 全部头文件
├── link.ld              # 链接脚本
└── Makefile
```

## 环境要求与快速开始

工具链:`arm-none-eabi-gcc` + `openocd`(ST-Link)

```bash
make            # 编译并链接,生成 rtos.elf
make flash      # 通过 ST-Link 烧录并复位运行
make clean
```

## 内核架构速览

- **调度**:`vTaskSwitchContext` 按优先级 0→3 找第一条非空就绪队列取队头;
  SysTick(1ms)把当前任务重挂回自己优先级的就绪队列队尾实现轮转,并置 PendSV 完成切换。
- **启动流程**:`rtos_start` 设置 PSP → `SVC` 弹伪造栈帧进入第一个任务。
- **临界区**:`rtos_enter_critical/rtos_exit_critical` 保存并恢复 PRIMASK,
  队列/信号量/互斥锁/内存池内部全部可嵌套使用。
- **内存布局**:TCB 池与任务栈位于片内 SRAM,堆池分配 32/64/128/256 四档。

## 同步原语

| 原语 | 说明 |
|---|---|
| `semaphore_p / v` | 计数信号量;为 0 时 P 阻塞挂入等待队列,V 唤醒队头 |
| `mutex_take / give` | 互斥锁;被占用则阻塞,**高优先级等待者会把持锁者抬升到自己的优先级**(继承),释放时锁**直接转交**队头等待者 |

## 功能演示(main.c)

演示程序由控制器任务每 5 秒切换一个阶段,循环往复。用逻辑分析仪观察:

| 引脚 | 阶段 0(0~5s):互斥 | 阶段 1(5~10s):优先级继承 |
|---|---|---|
| PA8 / PA9 | 任务 X / Y 的临界区脉冲 | — |
| PA6 | — | 低优先级 L 持锁忙 350ms |
| PC7 | — | 高优先级 H 每 ~700ms 抢锁成功(短脉冲) |
| PC8 | — | 中优先级 M 的运行方波 |

- 阶段 0 判据:PA8/PA9 高电平**永不重叠**;
- 阶段 1 判据:PC7 脉冲**稳定每 ~700ms 出现**(锁等待有界=继承生效);PC8 方波在 L 被抬升期间暂停。

## 开发记录(踩过的坑)

1. **临界区嵌套**:早期用 `cpsid/cpsie` 硬开关中断,内层函数退出时会把外层临界区误开。
   改为保存/恢复 PRIMASK 后可安全嵌套。
2. **互斥锁转交缺陷**:give 唤醒等待者时若直接把 owner 清空,等待者以为拿到锁但 owner=0,
   第三方会乘虚而入 → 互斥被破坏。修复:有等待者时**锁直接转交**,无人等才清空。
3. **让锁者丢失(最难查的一个)**:give 转交给更高优先级任务时立即 `PENDSVSET`,
   若让锁者还没来得及把自己挂入下一个队列就被 PendSV 切走,它会"无处可归"永久丢失
   (现象:低优先级任务只跑了一次就再也不被调度)。修复:让锁者**先把自己挂回就绪队列再请求切换**。
4. 头文件里放函数体、函数缺 `return`、优先级不够用(3 级扩到 4 级)等基本功问题。
